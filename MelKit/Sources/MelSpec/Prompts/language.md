## Language

Write everything the user reads in {{language}}: names, questions, options, notes, findings and the file's headings and prose. Keep these in English exactly as shown above, because Mel reads them: JSON keys and fixed values, IDs, `<!-- mel:… -->` lines, callout tags such as `[!ASSUMPTION]`, line labels such as `Source:`, `Covers:` and `Priority:`, tags such as `P1 · MVP`, the `Flow` in flow headings, and EARS keywords (WHEN, WHILE, IF, THEN, THE … SHALL).
