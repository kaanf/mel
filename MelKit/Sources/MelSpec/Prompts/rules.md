## Rules

- The file must be complete. Never write open questions, TBD, TODO or placeholders. When information is missing, choose the best option and wrap that decision in a `> [!ASSUMPTION]` callout.
- Each topic under "Decide and mark as assumption" gets an assumption callout where it applies:

> [!ASSUMPTION]
> The waitlist is first come, first served.

- An assumption is a full decision, written as a statement, not a question.
- Output only the file's Markdown (after the plan line, where one is asked for). No preamble, no closing remarks, no code fence around the file.
